## تسطيب التطبيق
1. نزّل ملف `yala-nel3ab.apk` من [صفحة الإصدارات](https://github.com/hesham-YxH/yala-nel3ab-app/releases/latest).
2. افتحه من الموبايل ودوس **Install**.
3. لو ظهر "مصدر غير معروف": **Settings** ← **Allow from this source** ← ارجع ودوس **Install**.

التطبيق موقّع رسمياً، ومن غير إعلانات، وبيطلب صلاحية الإنترنت والاهتزاز بس.
